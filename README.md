# 탭투게더 키오스크

가게에서 쓰는 주문 기계(키오스크) 화면이에요. 할머니, 할아버지도 쉽게 쓸 수 있게 만들었어요. 가족이 폰으로 같이 주문을 도와줄 수도 있어요.

세 가지가 같이 움직여요.

| 이름 | 하는 일 |
| --- | --- |
| **tap-together-app** (지금 보는 이 프로젝트) | 키오스크 화면 |
| **tap-together-web** | 폰으로 쓰는 리모컨 |
| 서버 | 둘을 이어 줘요. 이미 켜져 있어서 신경 안 써도 돼요 |

여러분은 **tap-together-app 과 tap-together-web, 두 개만** 내 것으로 복사해서 쓰면 돼요.

---

## 1. 내 것으로 만들기

두 프로젝트 **모두** 똑같이 해요. 프로젝트 이름은 바꾸지 마세요.

1. 오른쪽 위 **Fork** 버튼 → **Create fork** 를 눌러요. 내 것이 생겨요.
2. 내 것에서 **Actions** 탭 → 초록색 버튼(I understand my workflows...)을 눌러요.
3. **Settings** → 왼쪽 **Pages** → **Source** 를 **GitHub Actions** 로 바꿔요.
4. **Actions** 탭 → 왼쪽 **Deploy to GitHub Pages** → **Run workflow** → 초록 버튼. 1~2분 기다리면 초록색 체크(✓)가 떠요.

내 사이트 주소예요. `내아이디`는 내 GitHub 아이디예요.

- 키오스크: `https://내아이디.github.io/tap-together-app/`
- 리모컨: `https://내아이디.github.io/tap-together-web/`

## 2. 써 보기

1. 컴퓨터에서 키오스크 주소를 열어요. 숫자 6개와 QR 그림이 보여요.
2. 폰으로 QR을 찍으면 리모컨이 열려요.
3. 처음에는 30초~1분 걸릴 수 있어요. 기다리면 돼요.

---

## 3. 메뉴 바꾸기 (내가 직접)

`src/data/menu.js` 파일 하나만 고치면 돼요. **tap-together-app 과 tap-together-web 둘 다, 똑같이** 고쳐야 해요. 한쪽만 고치면 키오스크와 리모컨 화면이 서로 달라요.

메뉴 하나가 `{ }` 한 덩어리예요. 덩어리 안에서 바꾸고 싶은 것만 고쳐요.

| 이 줄을 고치면 | 바뀌는 것 |
| --- | --- |
| `names` | 메뉴 이름 (5개 나라 말) |
| `price` | 가격 (숫자만) |
| `icon` | 이모지 |
| `photo` | 사진 파일 이름 |
| `whip` | `true` 면 휘핑크림을 고를 수 있어요 |
| `iceOnly` | `true` 면 차가운 것만 있어요 |
| `category` | 어느 칸에 들어가는지: `coffee` `latte` `tea` `ade` 중 하나 |

**조심하세요**: 따옴표(`"`)와 쉼표(`,`)를 지우면 안 돼요. `id` 는 바꾸지 마세요.

**고치는 방법**
1. `src` → `data` → `menu.js` 를 열어요.
2. 오른쪽 위 연필(✏️) 모양을 눌러요.
3. 고치고, 오른쪽 위 **Commit changes** (저장하기) → 한 번 더 **Commit changes**.
4. 두 프로젝트 모두 했으면 **Actions** 탭에서 초록 체크(✓)를 기다려요. 그다음 사이트에서 **Ctrl + F5** 를 눌러 새로고침해요.

**새 메뉴 만들기**
1. 메뉴 덩어리 하나를 `{` 부터 `},` 까지 통째로 복사해요.
2. 마지막 덩어리 아래에 붙여넣어요.
3. `id` 를 새 영어 이름으로 바꿔요 (다른 메뉴와 겹치면 안 돼요). 이름, 가격, 이모지, 사진 이름도 바꿔요.

**사진 바꾸기**
1. `public` → `menu-images` 폴더를 열어요.
2. **Add file** → **Upload files** 로 사진(jpg)을 올려요.
3. 사진 파일 이름은 메뉴 덩어리의 `photo` 와 똑같아야 해요. 이름이 같으면 옛날 사진이 새 사진으로 바뀌어요.
4. 사진도 **두 프로젝트 모두** 올려야 해요.
5. 사진이 없으면 이모지가 대신 나와요.

## 4. ChatGPT에게 말로 시키기

코드를 몰라도 돼요. **우리 반 GPT**에게 말만 하면 ChatGPT가 내 프로젝트의 메뉴를 대신 바꿔 줘요. 앱과 웹, 두 곳을 한꺼번에 바꿔 줘서 따로 붙여넣을 필요가 없어요.

### 처음에 한 번만

1. 우리 반 GPT 링크를 열어요: **(여기에 GPT 링크)**
2. 처음 말을 걸면 **Sign in with github.com** 버튼이 나와요. 눌러서 허용해요. (내 GitHub 아이디로 내 프로젝트를 바꾸려고 하는 거예요.)
3. 내 프로젝트가 1번 방법으로 만들어져 있고, 두 곳 모두 **Actions**가 켜져 있어야 해요.

### 말로 시키기

이렇게 말하면 돼요.

> 아메리카노를 "초코빙수"로 바꿔 줘. 가격은 5000원, 이모지는 🍧로 해 줘.

> 딸기라떼 가격을 5000원으로 올려 줘.

> 새 메뉴 "망고주스"를 에이드에 만들어 줘. 가격은 4500원, 이모지는 🥭.

> 유자차 메뉴를 없애 줘.

GPT가 "이렇게 바꿀까요?" 하고 물어보면 "응"이라고 하세요. 그러면 바꿔요. 1~2분 뒤에 사이트에서 **Ctrl + F5**를 눌러 새로고침하면 보여요. 이름을 바꾸면 다른 나라 말 이름도 GPT가 알아서 번역해 줘요.

**사진은 GPT가 못 올려요.** 사진은 3번의 "사진 바꾸기"처럼 직접 올려야 해요. 사진이 없으면 이모지가 나와요.

### GPT가 안 될 때는 복사해서 붙이기

GPT 링크가 안 열리거나 GitHub 로그인이 안 되면 이렇게 해요.

1. 이 프로젝트의 **CHATGPT_PROMPT.md** 안의 선 사이 글을 전부 복사해서 ChatGPT 새 대화에 붙여넣고 보내요. "준비됐어요!" 라고 하면 돼요.
2. GitHub에서 `src/data/menu.js` 글을 전부 복사해서 붙여넣고, 바꾸고 싶은 걸 말해요.
3. ChatGPT가 준 글로 **menu.js 를 통째로 바꿔요** (연필 ✏️ → 안의 글을 전부 지우고 붙여넣기 → Commit changes). **tap-together-web 에서도 똑같이** 해요.

### 조심하세요

- 비밀번호나 개인 정보는 ChatGPT에 말하지 마세요.
- GPT가 메뉴 말고 다른 걸 바꿔 달라는 말을 못 들어 주는 건 정상이에요. 선생님께 물어보세요.

---

## 5. 안 될 때

| 이럴 때 | 이렇게 해 보세요 |
| --- | --- |
| Actions에 빨간 ✗ 가 떠요 | 따옴표나 쉼표를 지웠을 수 있어요. 빨간 ✗ 를 눌러서 나온 빨간 글을 ChatGPT에게 붙여넣고 고쳐 달라고 하세요. |
| GPT에게 시켰는데 "찾을 수 없어요(404)"라고 해요 | 내 프로젝트가 옛날 것일 수 있어요. 내 프로젝트 페이지에서 **Sync fork → Update branch** 를 누르고, Actions가 켜져 있는지 보세요. |
| 고쳤는데 그대로예요 | 1~2분 기다리고, 초록 체크(✓)가 뜬 다음 **Ctrl + F5** 를 눌러요. |
| 키오스크만 바뀌고 리모컨은 안 바뀌어요 | tap-together-web 의 `menu.js` 도 똑같이 고쳤는지 보세요. |
| 사진이 안 나오고 이모지만 나와요 | 사진 이름이 `photo` 와 똑같은지, 두 프로젝트 모두 올렸는지 보세요. |
| 리모컨이 연결이 안 돼요 | 1분 뒤에 다시 해 보세요. |
| 사이트가 "404" 라고 나와요 | Settings → Pages 의 Source 가 GitHub Actions 인지 보세요. 프로젝트 이름을 바꾸지 않았는지도 보세요. |
