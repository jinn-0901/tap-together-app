# 새 리모컨 기능 만들기

리모컨에 **새 버튼**을 만들 수 있어요. 버튼을 켜면 키오스크 화면이 바뀌어요. (예: 🌙 어두운 화면, 🎨 알록달록 화면, 🔍 아주 큰 가격)
메뉴 바꾸기와 똑같이 ChatGPT에게 말하고, "글 한 줄"을 붙여넣으면 돼요.

## 원리 (쉬운 그림)

```
리모컨 버튼을 눌러요 ──▶ 서버가 "dark-mode 켜짐!"을 키오스크에 전달 ──▶ 키오스크 화면 맨 위에 "fx-dark-mode" 표시가 붙어요 ──▶ 그 표시가 있을 때만 적용되는 꾸미기 규칙(CSS)이 화면을 바꿔요
```

- **이름표(id)**: 기능의 영어 이름. 예: `dark-mode`
- **꾸미기 규칙(css)**: 기능이 켜졌을 때 화면을 어떻게 바꿀지. 모든 규칙은 `.fx-이름표` 로 시작해요.

## 만드는 순서

1. [`CHATGPT_PROMPT.md`](../CHATGPT_PROMPT.md) 로 알려 준 ChatGPT 대화에서 말해요. 예:
   - `리모컨에 "어두운 화면" 버튼을 만들어 줘. 켜면 키오스크가 어두워져`
   - `"글자 아주 크게" 버튼을 만들어 줘`
2. ChatGPT가 만든 **코드 상자의 한 줄**을 복사해요.
3. GitHub의 **tap-together-app** → **Actions** → **Edit menu (ChatGPT helper)** → **Run workflow** → 붙여넣기 → 초록 버튼.
4. **tap-together-web 에서도 똑같이** 해요. (같은 줄을 한 번 더 붙여넣어요.)
5. 1~2분 뒤 **키오스크와 리모컨 둘 다 Ctrl + F5**. 리모컨에 새 버튼이 생겼어요!
6. 키오스크 숫자를 입력해서 연결하고, **직접 도와주는 사람**으로 들어가서 버튼을 눌러 보세요.

## 지우기

`리모컨의 "어두운 화면" 버튼을 지워 줘` 라고 말하고, 나온 한 줄을 두 곳에 똑같이 붙여넣어요.

## 알아 두세요

- 버튼은 **직접 도와주는 사람**만 눌러요. (같이 보는 사람 화면에는 보이지 않아요.)
- 연결이 끊기면 새 기능은 꺼진 채로 다시 시작해요.
- 화면의 **모양**(색, 크기, 숨기기, 모양 바꾸기)은 바꿀 수 있어요. **새 동작**(소리 내기, 주문 넣기 같은 것)은 못 만들어요.
- 버튼 이름은 5개 나라 말로 써 줘요. 없는 말은 영어로 보여요.
- 이름표는 영어 소문자로 시작하고, 소문자·숫자·하이픈만, 30자까지예요. `easy-mode`, `voice`, `large-text`, `high-contrast`, `voice-guide` 는 이미 있어서 못 써요.
- 안 될 때: Actions의 빨간 ✗ 를 눌러 나온 글을 ChatGPT에게 보여 주세요. 키오스크(app)와 리모컨(web) 중 한쪽만 했는지도 확인해요.
