# 메뉴 직접 고치기

ChatGPT(우리 반 GPT)가 안 될 때, 또는 사진을 바꿀 때 쓰는 방법이에요.

> **꼭 기억하세요**: 아래는 **tap-together-app 과 tap-together-web 둘 다, 똑같이** 해야 해요. 한쪽만 하면 키오스크와 리모컨 화면이 서로 달라요.

---

## 1. 메뉴 글 고치기

고치는 파일은 `src/data/menu.js` **하나**예요. 메뉴 하나가 `{ }` 한 덩어리고, 안에서 바꾸고 싶은 줄만 고쳐요.

| 이 줄을 고치면 | 바뀌는 것 |
| --- | --- |
| `names` | 이름 (5개 나라 말) |
| `price` | 가격 (숫자만) |
| `icon` | 이모지 |
| `photo` | 사진 파일 이름 |
| `whip` | `true` 면 휘핑크림을 고를 수 있어요 |
| `iceOnly` | `true` 면 차가운 것만 있어요 |
| `category` | `coffee` `latte` `tea` `ade` 중 하나 |

**조심**: 따옴표(`"`)와 쉼표(`,`)를 지우면 안 돼요. `id` 는 바꾸지 마세요.

**고치는 방법**
1. `src` → `data` → `menu.js` 를 열고 오른쪽 위 연필(✏️)을 눌러요.
2. 고친 다음 **Commit changes** (저장하기)를 두 번 눌러요.
3. **Actions** 탭에서 초록 체크(✓)를 기다린 뒤 사이트에서 **Ctrl + F5**.

**새 메뉴 만들기**: 메뉴 덩어리 하나를 `{` 부터 `},` 까지 복사해서 맨 아래에 붙이고, `id` 를 새 영어 이름으로 바꿔요 (다른 메뉴와 겹치면 안 돼요).

---

## 2. 사진 바꾸기

1. `public` → `menu-images` 폴더를 열어요.
2. **Add file** → **Upload files** 로 사진(jpg)을 올려요.
3. 파일 이름은 메뉴 덩어리의 `photo` 와 똑같이 해요. 이름이 같으면 옛날 사진이 새 사진으로 바뀌어요.
4. 사진이 없으면 이모지가 대신 나와요.

---

## 3. ChatGPT에게 글만 만들어 달라고 하기 (GPT 링크가 안 될 때)

1. 이 프로젝트의 **CHATGPT_PROMPT.md** 안의 선 사이 글을 전부 복사해서 ChatGPT 새 대화에 붙여넣고 보내요. ("준비됐어요!" 라고 하면 돼요.)
2. GitHub에서 `src/data/menu.js` 글을 전부 복사해서 붙여넣고, 바꾸고 싶은 걸 말해요.
3. ChatGPT가 준 글로 `menu.js` 를 **통째로 바꿔요** (연필 ✏️ → 안의 글을 전부 지우고 붙여넣기 → Commit changes).
4. **tap-together-web 에서도 똑같이** 해요.
