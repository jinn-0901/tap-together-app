탭투게더 메뉴 도우미 개인정보 안내

이 도우미가 하는 일

학생이 ChatGPT에서 "메뉴 이름 바꿔줘"라고 말하면, 학생의 GitHub 프로젝트(tap-together-app, tap-together-web)에서 메뉴 수정 작업을 실행해 줘요.

어떤 정보를 쓰나요

  • GitHub 로그인을 해서, 학생의 GitHub 아이디를 알아내요.
  • 학생이 말한 메뉴 수정 내용(메뉴 이름, 가격 등)을 학생의 GitHub 프로젝트로 보내요.

저장하나요

이 도우미를 만든 사람은 학생의 GitHub 비밀번호나 로그인 토큰을 받지 않고, 따로 저장하지도 않아요. 로그인 정보는 ChatGPT(OpenAI)가 관리해요. 학생은 언제든 GitHub의 Settings → Applications 에서 연결을 끊을 수 있어요.

문의

궁금한 점은 github.com/jinn-0901/tap-together-app 에 남겨 주세요.

English

This helper signs in with GitHub to read your GitHub username and to run a menu-edit workflow in your own tap-together-app and tap-together-web projects. The creator of the helper does not receive or store your GitHub password or access token; sign-in is handled by ChatGPT (OpenAI). You can disconnect at any time in GitHub under Settings → Applications.
